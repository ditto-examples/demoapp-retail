# flutter/ — Zava Retail (Flutter port, PLAN M3)

Flutter port of the SwiftUI reference (swift/), UI-matched to the Android app
(android/). Nearest AGENTS.md wins; the repo root's rules (singleton
DittoManager, DQL visible at call sites, benchmark transformations) apply here.

## Environment

- **fvm-managed Flutter**: pinned via `.fvmrc` to **3.47.0** (Dart 3.13.0 —
  the M3 verification gate; `ditto_live` 5.1.0 + `ditto_flutter_tools` 3.0.0
  verified building on it). Run everything through fvm:
  `cd flutter && fvm flutter …`.
- **Env**: `.env` at the repo root, injected at build/run time with
  `--dart-define-from-file=../.env` (String.fromEnvironment reads).
- **Assets**: `assets/benchmarks.json` is a SYMLINK to `../shared/benchmarks.json`
  (Flutter assets must live under the package root; the symlink keeps one
  source of truth). Regenerate the target via `scripts/sync_benchmarks.sh`,
  never edit the symlink's content directly.

## Platform build gotchas (already worked around — don't regress)

- **Android compileSdk**: Ditto's `transports-android` 5.1.x requires
  compileSdk 36+, but `ditto_flutter_tools` pins 35. `android/build.gradle.kts`
  forces every library subproject to `compileSdk = 36` in an `afterEvaluate`
  block that MUST run before `evaluationDependsOn(":app")`.
- **iOS simulator x86_64**: DittoCore.xcframework is arm64-only for the
  simulator (SDKS-3740). `Flutter/Generated.xcconfig` (regenerated by the
  tool, do NOT edit) clobbers the Pods `EXCLUDED_ARCHS[sdk=iphonesimulator*]`
  exclusion; `Flutter/Debug.xcconfig` and `Flutter/Release.xcconfig` re-apply
  `i386 x86_64` AFTER the Generated include. Without this, `flutter build ios
  --simulator` fails with `framework 'DittoCore' not found`.
- **`Ditto.init()` must be awaited first** — even the static
  `Ditto.defaultRootDirectory` throws "Ditto not initialized" otherwise.

## Conventions

- **Riverpod 3** for app-level state (`state/app_state.dart`); screens hold
  their own observer state in StatefulWidgets (1:1 with the reference apps'
  screen-state classes), cancelling observers in `dispose()`.
- **snake_case model fields** mirror the Ditto documents exactly (lint
  `non_constant_identifier_names` disabled in analysis_options.yaml with a
  comment — keep it off; the mapping visibility is the point).
- **Adaptive navigation**: `MediaQuery.sizeOf(context).width >= 600` switches
  the shell between a bottom `NavigationBar` and a side `NavigationRail`
  (phone ↔ Fold inner display / tablet), reactive on fold/unfold.
- Decode from `item.value` maps (the Flutter SDK manages cursor lifetime by
  GC — there is no dematerialize contract here, unlike Kotlin/Swift).
- Dart has no structured concurrency: benchmark cleanup can't be cancelled by
  widget disposal (no NonCancellable equivalent needed) — the runner comment
  in `models/benchmark_catalog.dart` records this.
